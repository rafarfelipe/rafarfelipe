## About

I'm a QA Automation Engineer and Software Engineering student focused on building **fast, reliable, and scalable test suites** that give teams the confidence to ship.

I work across the full testing stack — manual exploratory testing, web and mobile automation, REST API contracts, database integrity checks, and CI/CD gates. My goal is to make quality a non-negotiable part of the delivery pipeline.

- **Manual Testing** — exploratory sessions, test case design, bug discovery
- **Automation** — Cypress, Playwright, Maestro, Selenium
- **API Testing** — Postman, Newman, REST Assured
- **Performance** — k6, JMeter
- **CI/CD & DevOps** — GitHub Actions, Docker
- **Databases** — PostgreSQL, MySQL, SQL
- **QA Management** — Jira, Xray, TestRail
